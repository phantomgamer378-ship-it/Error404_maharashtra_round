# Error404_maharashtra_round
## VIDORA — AI Creator Operating System
### Built by Team Error404 for Maharashtra Round

> **"Know what to create, extract what matters, and adapt everywhere."**
> 
> *About: Visual Intelligence for Digital Optimization, Reach & Amplification.*

VIDORA is an intelligent operating system designed for modern creators. It closes the loop between **trend intelligence (Trend.Ai)**, **raw footage intelligence**, **AI-assisted video editing (Studio Editor)**, **multi-platform adaptation**, and **continuous performance learning**.

---

## 🌟 Key Highlights & Architecture

### 1. Trend.Ai Intelligence Layer
- **Multi-Factor Interpretable Scoring Engine**: Mathematical scoring factoring Velocity, Saturation, Creator DNA Fit, and Audience Demand.
- **Interactive Topic Radar Network**: Node graph with velocity vectors and saturation indicators.
- **Trend Trajectory Visualizer**: 30-day projection curves comparing viral spikes vs sustained search growth.
- **Content Gap Finder**: Identifies under-saturated creator opportunities with audience hunger.

### 2. Creator DNA Calibration
- Dynamic persona model tuned to the creator's niche (Technology & Cybersecurity), target audience (18–25 tech-savvy), humor/education tone balance, and preferred hook styles.
- Continuous learning loop that automatically boosts Creator Fit (`+15pt`) based on historical video retention and engagement.

### 3. Raw Footage Intelligence
- Multi-stage pipeline:
  1. Media container parsing & resolution validation (4K ProRes 60fps)
  2. Whisper AI transcription with word-level timestamps
  3. Semantic topic boundary chunking
  4. Curiosity spike & retention ranking
  5. Script alignment against Creator DNA
  6. 9:16 vertical crop extraction with safe-area calculations

### 4. Flagship Video Studio Editor
- HTML5 Canvas Player synced to a multi-track timeline (Video, Text Overlay, Captions, Audio).
- Social 9:16 safe-zone overlay guidelines (TikTok, Reels, Shorts).
- Contextual Floating AI Toolbar on element selection (✨ Improve, 🔥 Hook Boost, 🧠 Simplify).
- Persistent Command Bar with 7 instant chip actions.
- Zod-validated Editor AI Copilot with scoped editing enforcement (Rule 5).
- Integrated AI Changes Log with per-operation undo.

### 5. Multi-Platform Adaptation
- Genuine rewriting engine for Instagram Reels, YouTube Shorts, LinkedIn Tech Breakdowns, and X Threads.
- Calibrates duration, tone, hooks, aspect ratios, and platform-native CTAs.
- Visual content-tree mapping from source master to all derived platform assets.

### 6. What-If / Variant Engine
- Side-by-side comparison of 3 hook alternatives (A/B/C) with estimated retention curves and audience fit indicators.
- One-click application directly into the timeline.

### 7. Continuous Performance & Learning Loop
- Deterministic performance analytics (Views, Watch Time, Retention %, Saves, Shares, CTR).
- Plain-language AI Insights without fabricated metrics.
- 5-stage automated calibration loop updating Creator DNA and re-ranking the Trend Radar with live badges (`⚡ Updated from your latest performance`).

## 🚀 Quick Start Guide

### Prerequisites
- Node.js 18+
- npm or pnpm

### Installation
```bash
# Clone the repository
git clone https://github.com/phantomgamer378-ship-it/Error404_maharashtra_round.git
cd Error404_maharashtra_round

# Install dependencies
npm install

# Start the development server
npm run dev
```

Visit **`http://localhost:3000`** in your browser.

## 🛠️ Technology Stack
- **Framework**: React 18 + Vite (SPA)
- **Language**: TypeScript (strict mode)
- **Styling**: Tailwind CSS + Custom 4-Tier Glassmorphic Tokens (`glass-panel-l1` to `l4`)
- **Motion**: Framer Motion
- **Icons**: Lucide React
- **Validation**: Zod
- **Typography & Accessibility**: Tabular Numerals (`tnum`), 8pt grid rhythm, WCAG AA compliance, prefers-reduced-motion support.
